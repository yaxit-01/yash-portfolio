## 💻 Local Development & Deployment

### Prerequisites
- Node.js (v18+)
- npm

### Run Locally
```bash
# 1. Clone repository
git clone https://github.com/yaxit-01/yash-portfolio.git
cd yash-portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Run linting
npm run lint

# 5. Build for production
npm run build

# 6. Preview production build locally
npm run preview
```

### Deploy to GitHub Pages
```bash
# Deploys dist/ directory to gh-pages branch
npm run deploy
```
